# Casa Felicis

Landing page institucional para a marca de licores artesanais Casa Felicis, com apresentação dos produtos, receitas e caminhos de contato e compra.

## Tecnologias

- HTML5
- JavaScript puro
- Tailwind CSS via CDN
- Google Fonts
- Assets locais de imagem

## Recursos e desafios

- Direção visual responsiva para uma marca de bebidas premium.
- Navegação por história, catálogo de licores e sugestões de cocktails.
- Páginas dedicadas aos sabores Abacaxi e Chocolate.
- Integração de chamadas para Instagram e WhatsApp.

## Executar localmente

Não há dependências de instalação ou etapa de compilação versionadas. Abra `index.html` em um navegador ou sirva a pasta com um servidor HTTP local.
